# Aula_Mobil
This system is an Android mobile app built with Kotlin and Jetpack Compose that connects to a real backend API to let a student view their own academic information.  Here's what it actually does, Login: the user enters their student ID and password. The app sends these to a login endpoint, and the server responds with a security token if the credentials are correct. Session handling: that token gets saved securely on the device (using DataStore, not plain text), and gets automatically attached to every future request to the server, so the user doesn't have to log in again each time they reopen the app. Profile screen: shows the student's name and ID number, pulled from the data the server returned at login. Grades screen: fetches all academic data from the server (assignments, exam results, manual grades) and combines it into one report card view, including a calculated overall average. Attendance screen: fetches and displays attendance records per class session, with a color-coded status (present, absent, late, excused). Logout: sends a request to the server to actually invalidate the session, not just delete the token locally. Error handling: if login fails, if there's no internet connection, or if the session expires mid-use, the app shows a clear message and — in the case of an expired session — sends the user back to the login screen automatically. Dark mode: a toggle in the profile screen that switches the whole app's color scheme.
